# Centrifugo v6 Admin Dashboard (管理后台) 使用与调试指南

本指南详细介绍了 Centrifugo v6 官方可视化管理后台（Admin Dashboard）的各项功能模块、运行指标解读，以及如何直接在后台进行消息推送和长连接运维调试。

---

## 1. 访问与入口配置

在生产和本地容器环境下，管理控制台已被安全地映射并代理：

* **访问 URL**：`https://push.test.local/admin/` (已通过 Caddy 自动放行该路径)
* **登录凭证**：
  * **用户名**：默认无，只需在密码框中输入密码。
  * **密码**：对应宿主机 `.env` 文件中的 **`CENTRIFUGO_ADMIN_PASSWORD`** 变量值。

> [!CAUTION]
> 生产环境安全警告：管理后台拥有对所有长连接通道的最高操作权限（包括断开用户、群发消息等）。请务必使用强随机算法生成密码，并在网关（如 Caddy/Nginx）上限制该路径仅限企业内网或 VPN 访问。

---

## 2. “Status” (状态监控仪表盘)

“Status” 是管理后台的主入口，提供全集群和单节点的实时流量监控：

```text
📊 核心监控指标：
├── NODES RUNNING：当前集群中在线的 Centrifugo 节点数 (单实例部署为 1)。
├── TOTAL CLIENTS：全集群当前维持的长连接物理设备数。
└── TOTAL SUBS   ：全集群总频道订阅次数 (单个 Client 可以订阅多个频道)。
```

### 节点详情表格说明：

* **Node name**：自动映射当前 Docker 容器的主机 ID 加上端口，便于在多节点集群中定位具体机器。
* **Uptime**：本节点的不间断运行时间。如果持续运行时间过短，说明服务可能刚刚发生过崩溃重启（OOM 或网络故障），需要及时检查容器日志。
* **Users**：当前去重后的独立登录用户数。

## 3. “Actions” (管理控制命令面板) —— 核心调试区

“Actions” 面板是 Centrifugo 提供的**免代码测试控制台**。管理员可以直接在浏览器内模拟后端服务器，向 Centrifugo 下达核心 API 控制指令。

### 3.1 Method: Publish (向指定频道实时推送消息)

* **适用场景**：模拟后端业务逻辑，直接对在线的前端客户端推送最新数据。
* **配置步骤**：
    1. 在 **Method** 下拉框中选中 `Publish`。
    2. 在 **Channel\*** 输入框中输入要接收消息的频道名称（如公开聊天频道 `public:chat_room_1` 或个人红点通道 `user:user_9958`）。
    3. **Idempotency Key**（幂等键，选填）：若填入强随机字符串，可以防范网络超时导致的数据重复发送。
    4. **消息负载编辑框 (JSON)**：在底部输入框输入具体的业务 JSON 载荷。
        * *示例载荷*：

          ```json
          {
              "message": "这是由管理员直接在 Dashboard Actions 界面推送的测试公告！",
              "type": "system_notice"
          }
          ```

    5. 点击 **PUBLISH** 按钮，该频道在线的所有客户端均能毫秒级收到该消息。

---

### 3.2 Method: Broadcast (向多个频道同时广播)

* **适用场景**：紧急停机公告、多房间游戏赛事开幕群发。
* **操作要点**：
  * `Channels` 输入框支持输入多个频道名称，用逗号或回车分隔。
  * 发送后，这些通道里的所有客户端会同步收到一份相同的数据。

---

### 3.3 Method: Disconnect (强制断开特定客户端长连接)

* **适用场景**：恶意连接清洗、用户因违规被强行踢下线。
* **操作要点**：
  * 需要指定 **`User*`**（用户唯一 ID）或特定的 **`Client*`**（长连接实例 ID）。
  * 支持配置断连代码（`Disconnect Code`，默认为 3000）和自定义断连原因（`Reason`），这些会被原封不动地返回给前端长连接的 `onclose` 事件，便于前端执行逻辑拦截（如提示“您的账号已在别处登录”）。

---

### 3.4 Method: Unsubscribe (强制取消订阅某个频道)

* **适用场景**：用户退出了某个收费房间，强制剥夺其监听权。
* **操作要点**：
  * 指定要剥夺的 **`User*`** 或 **`Client*`** 以及目标 **`Channel*`**。
  * 取消订阅后，客户端物理 TCP 连接还在，但将再也收不到该频道的任何消息。

---

### 3.5 Method: Presence & Presence Stats (查询通道在线人员列表)

* **适用场景**：查看当前谁正在聊天室里，检测活跃度。
* **操作要点**：
  * 输入目标频道名称（如 `public:chat_room_1`）。
  * 运行后，控制台会输出当前连在这个频道上的所有用户的 `client_id` 以及他们的长连接元数据。

---

### 3.6 Method: History (读取频道在 Valkey 中的消息历史记录)

* **适用场景**：调试重连恢复机制是否正常缓存了消息。
* **操作要点**：
  * 输入频道名。
  * 运行后会返回当前缓存在后端 Valkey 中的历史消息流队列。
